How THERESE reads outbound mail settings from .env

Where settings live

  • Secrets belong in the file .env in the project root (same folder as manage.py). That file is gitignored and must not be pushed to GitHub.
  • The generic template is .env.example. It is versioned. Copy it to .env on a new server, then fill in real values: python create_env_template.py
  • After changing .env, restart the application so Django reloads the values.

Passwörter nur in der lokalen .env, niemals im Repository.
